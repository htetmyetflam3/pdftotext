01 how it works သုံးဆင့်ပဲ ရှိတယ်

PDF ထဲက font mapping ကနေ — စစ်ဆေးလို့ရတဲ့ စာသားထိ

01

စာသားအလွှာပါတဲ့ PDF ကို ရွေးပါ

လက်ရှိ extraction လမ်းကြောင်းက selectable text ပါတဲ့ PDF အတွက် ဖြစ်ပါတယ်။ ပုံအဖြစ် scan လုပ်ထားတဲ့ စာမျက်နှာတွေကတော့ OCR လမ်းကြောင်း လိုအပ်ပါတယ်။

text-based · .pdf
02

ဖောင် mapping ကို စာမျက်နှာအလိုက် ဖတ်တယ်

Parser က embedded font mapping ကို စစ်ဆေး၊ Zawgyi/Unicode ကို စာမျက်နှာအလိုက် ခွဲခြားပြီး လိုအပ်တဲ့ စာသားပြောင်းလဲမှုကို လုပ်ပါတယ်။

font map · detect · convert
03

မူရင်းနဲ့ စစ်ပြီး ထုတ်ယူပါ

ထုတ်ယူထားတဲ့ စာသားကို မူရင်း PDF နဲ့ နှိုင်းယှဉ်စစ်ဆေးပြီး ကူးယူနိုင်သလို TXT သို့မဟုတ် DOCX အဖြစ် ဆက်သုံးနိုင်ပါတယ်။

review · .txt · .docx
02 comparison တခြားကိရိယာတွေနဲ့ ချိန်ကြည့်ပါ

Text extraction နဲ့ OCR — ဘယ်အချိန် ဘာသုံးမလဲ
